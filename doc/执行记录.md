**开发周期**：2026-02-05 ~ 2026-02-12 ｜ **规模**：`140 commits, 63 files changed, 9475 insertions(+), 1561 deletions(-)`

本周期为功能密集期，主要工作按主题归纳：

**1. 交互式引导系统与多语言手册**

- 引入完整交互式引导（Guide Overlay）与用户手册，支持按平台环境自动切换默认 Tab、多语系术语标准化、手册 Tab 文字自适应缩放。
- 新增 PWA 安装示意图预览、演示视频嵌入与媒体加载指示器。

**2. PWA 移动端深度适配**

- 系统性解决 iOS PWA 视口高度、安全区域（Safe Area）、弹性滚动与白边问题，产出 `doc/ios-pwa-viewport-fix.md`。
- 修复 Android PWA 顶部蓝线瑕疵，加固 Service Worker 更新提醒机制。
- 新增 Android 原生安装提示、PWA 离线可用性与智能安装触发/冷却策略，产出 `doc/PWA_SPEC.md`。

**3. 跨平台与主题系统**

- 统一平台环境检测逻辑（扩展 / PWA / iOS 快捷指令 / 移动端 Web），实现跨平台 Canvas 适配层与显存管理机制。
- 支持「系统主题」跟随，分离模态浮层样式、消除全局样式污染。

**4. 后端服务与安全加固**

- Cloudflare Workers 代理与 API 加固：跨域来源校验、基于 Cache API 的请求限流、SSRF 防御、User-Agent 统一、错误状态码细分（修复笼统 502）。
- 引入 `VITE_APP_TOKEN` 环境变量管理应用令牌，部署工作流同步注入。

**5. 构建与发布体系**
