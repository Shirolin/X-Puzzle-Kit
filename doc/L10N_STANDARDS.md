# X-Puzzle-Kit L10n 全球化术语与排版规范

本规范旨在确保在新增功能或翻译时，UI 语言能保持 Apple/Google 级原生感，并完美适配侧边栏物理宽度。

## 1. 物理排版限制

- **侧边栏宽度**：262px (固定)。
- **词长建议**：
  - **西文 (es/fr/de)**：标题超过 15 个字符时，优先考虑使用缩略词或同义近词（如：`Galerie` 优于 `Ordre des images`）。
  - **CJK (zh/ja/ko)**：标题建议控制在 6 个字以内，避免双行折行。

## 2. 术语一致性表

| 功能区        | 英文 (en)         | 推荐中/日/韩/法/西翻译                               | 备注                                      |
| :------------ | :---------------- | :--------------------------------------------------- | :---------------------------------------- |
| **图片排序**  | `Image Sorting`   | Galerie (es/fr) / 並べ替え (ja) / 이미지 정렬 (ko)   | es/fr 统一使用 Galería/Galerie 以节省空间 |
| **导出设置**  | `Export Settings` | Export (fr) / 書き出し設定 (ja) / 내보내기 설정 (ko) | 法语强制精简为 Export                     |
| **赞助/支持** | `Buy me a coffee` | 支持 / 支援 / 지원 / Soutenir / Apoyar               | 避免直译“咖啡”，使用更自然的“支持”        |

## 3. 各语种优化原则 (Design Principles)

- **Spanish (es)**：去除多余的冠词（如 `el/la`）和介词。
- **Japanese (ja)**：避免过长的外来语（カタカナ），优先使用简练的名词词组。
- **Korean (ko)**：使用现代 App 惯用的名词化结尾（如 `저장` 优于 `저장하기`）。
- **French (fr)**：由于词长普遍偏长，允许合理使用缩写（如 `RAZ` 代替 `Remise à zéro`）。
