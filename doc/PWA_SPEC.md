# PWA 技术规范与配置总结

本文档总结了 X-Puzzle-Kit 在 PWA（渐进式 Web 应用）方面的方案设计，包括安装提醒、更新机制及各平台适配情况。

## 1. PWA 安装提示 (Install Prompt)

为了平衡转化率与用户体验，安装提示采用“非侵入式”设计：

- **触发逻辑**：**成功驱动型 (Success-Driven)**。移除页面加载时的自动弹出，仅在用户成功完成一次“拼接并下载”导出图片后触发。此时用户心理处于“获得感”最强时刻。
- **频率控制**：**7 天严格冷却期**。一旦用户关闭提示（点击 X），系统会记录时间戳。组件在收到触发事件时会强制校验 `localStorage`，7 天内禁止再次弹出。
- **不同终端表现**：
  - **Android (原生)**：支持 `beforeinstallprompt` 事件，显示原生“安装”按钮，一键调起系统安装。
  - **Android (手动引导)**：若浏览器不支持原生事件，显示指向**右上角菜单**的视觉箭头，引导用户手动点击“安装应用”。
  - **iOS**：识别平台及浏览器类型。
    - **Safari**：提示点击底部“分享”图标 -> “添加到主屏幕”。
    - **Chrome (iOS)**：提示点击地址栏右侧“分享”图标 -> “添加到主屏幕”。
  - **静默处理**：若应用已处于 `standalone` 模式或从 iOS 快捷指令（`source=shortcut`）打开，安装提示将完全屏蔽。

## 2. PWA 升级与更新逻辑

- **更新模式**：`registerType: 'prompt'`。检测到新版本后，通过 UI 提示用户，而非强制刷新。
- **普通 Web 访问**：右下角弹出 Toast 提示“新版本可用”。用户可选择“立即刷新”或“忽略（稍后）”。
- **iOS 快捷指令访问**：**无感静默更新**。针对快捷指令用户（通常追求极快速度），如果应用当前处于空闲状态（画布无图片），系统会自动触发 SW 升级并重载页面，确保下次打开是最新版。

## 3. 离线支持与缓存策略

- **全离线能力**：核心资源（JS/CSS/HTML）及本地资源（图标/SVG）均由 Service Worker 预缓存。
- **第三方资源缓存**：通过 Workbox 运行时缓存 Google Fonts 等外部依赖。
- **离线指示器**：Header 实时监听 `navigator.onLine`。离线时显示闪电图标及“离线可用”状态，增强用户对 PWA 特性的感知。

## 4. 环境隔离与性能

- **条件构建**：通过 `__IS_EXTENSION__` 编译宏确保 PWA 特有代码不会加载到 Chrome 插件中，反之亦然。
- **沉浸式体验**：适配 iOS 全屏模式，支持 `black-translucent` 状态栏，使背景色延伸至刘海区域。
- **系统集成**：配置 Web Manifest 的 `share_target`，支持 Android 系统级多图分享导入。
